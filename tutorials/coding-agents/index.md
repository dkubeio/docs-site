# Coding Agents

DKubeX Workspace ships with AI coding agents built in. These tutorials cover getting an agent
running and then putting it to work: sign in to Claude Code with your own Claude subscription, or
point it at DKubeX or OpenRouter models through the platform — and then have the agent build a web
app and host it straight from the Workspace, reachable through the built-in reverse proxy.

Start here if you want to code with an AI agent inside your Workspace and ship what it builds.

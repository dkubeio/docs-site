# Getting help

## When something doesn't work

- **[Troubleshooting](../reference/troubleshooting.md)** lists every known problem in these docs, with a
  link to the page that explains the fix.
- **[Glossary](../getting-started/glossary.md)** explains the terms used across these docs, with a link to
  the page that covers each one.
- **Search**, at the top of every page, searches all pages of the version you are reading.
- If you run an older version of DKubeX, read the docs for that version: see
  [Docs versions](docs-versions.md).

## Tell us about a page

At the end of every page, **Was this page helpful?** asks for a quick **Yes** or **No**. If you choose
**No**, a short form opens where you can describe what was missing or wrong, with your work email so we
can follow up.

The source of these docs is public on GitHub, in
[dkubeio/docs-site](https://github.com/dkubeio/docs-site).

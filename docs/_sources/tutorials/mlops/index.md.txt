# MLOps

Beyond serving language models, DKubeX runs your own machine learning workloads. This tutorial takes
a model through the full lifecycle on the platform — preparing the data, training the model, and
deploying it as a live endpoint you can send predictions to.

Start here if you're bringing a custom ML model to DKubeX rather than consuming a hosted LLM.

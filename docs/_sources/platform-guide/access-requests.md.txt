# Access Requests

When a user requests access to an application they aren't assigned to, the request appears here for an
administrator to approve or dismiss.

Open the admin console → **Applications** → the **Access Requests** tab. The tab label shows the number
of pending requests.

Each request row shows the **User**, the **App** requested, an optional **Message**, the **Submitted**
date, and a **Status** (pending).

## Approve a request

1. On the **Access Requests** tab, find the request.
2. In the row, choose the role to grant from the dropdown (**User** or **Admin**).
3. Click **Grant access**.

The user is assigned to the application with the chosen role and can open it on their next sign-in.

## Dismiss a request

1. On the **Access Requests** tab, find the request.
2. Click **Dismiss**.

The request is closed without granting access. The user is not assigned to the application.

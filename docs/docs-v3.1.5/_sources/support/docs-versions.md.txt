# Docs versions

These docs are published once per DKubeX version. The newest version is served at the root of the site,
https://dkubex2.dkube.io/, and every version, the newest included, is also kept at its own address. To
switch versions, use the version menu at the top of any page.

| Version | Docs | GitHub release |
|---|---|---|
| v3.1.5 (latest) | https://dkubex2.dkube.io/ and https://dkubex2.dkube.io/docs-v3.1.5/ | [v3.1.5](https://github.com/dkubeio/docs-site/releases/tag/v3.1.5) |
| v3.1.3 | https://dkubex2.dkube.io/docs-v3.1.3/ | [v3.1.3](https://github.com/dkubeio/docs-site/releases/tag/v3.1.3) |
| v2.1.4 | https://dkubex2.dkube.io/docs-v2.1.4/ | [v2.1.4](https://github.com/dkubeio/docs-site/releases/tag/v2.1.4) |
| v0.2.2 | https://dkubex2.dkube.io/docs-v0.2.2/ | [v0.2.2](https://github.com/dkubeio/docs-site/releases/tag/v0.2.2) |
| v0.2.0 | https://dkubex2.dkube.io/docs-v0.2.0/ | [v0.2.0](https://github.com/dkubeio/docs-site/releases/tag/v0.2.0) |
| v0.1.5 | https://dkubex2.dkube.io/docs-v0.1.5/ | [v0.1.5](https://github.com/dkubeio/docs-site/releases/tag/v0.1.5) |
| v0.1 | https://dkubex2.dkube.io/docs-v0.1/ | [v0.1](https://github.com/dkubeio/docs-site/releases/tag/v0.1) |

All docs releases are listed on the [docs-site Releases page](https://github.com/dkubeio/docs-site/releases).
Pages of an older version show a banner at the top with a link to the same page in the latest version.
